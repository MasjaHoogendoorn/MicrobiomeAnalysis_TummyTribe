# Infant Gut Microbiome Analysis (TummyTribe)

This repository contains a reproducible analysis pipeline for studying early-life gut microbiome development using longitudinal 16S rRNA gene amplicon sequencing data from a subset of the DIABIMMUNE cohort. The project focuses on microbiome changes between 4, 7, and 10 months of age and evaluates the influence of feeding type, geographic location, and treatment exposure.

## Project overview
Early infancy is a critical window for gut microbiome development. Using longitudinal infant stool samples, this project aims to characterize age-related changes in the infant gut microbiota, assess the impact of feeding type (breast-fed versus formula-fed), evaluate the influence of geographic location and treatment exposure, identify shared and diet-specific core microbiota, and explore functional differences using predicted metagenomes.

## Data
The dataset consists of infant fecal samples from the DIABIMMUNE cohort collected at 4, 7, and 10 months of age. Associated metadata include age in months, feeding type, geographic location, delivery mode, sex, and treatment exposure. Raw sequencing data are not included in this repository due to privacy restrictions.

## Analysis workflow
All analyses were performed using QIIME 2 and downstream Python and R tools. The workflow includes quality control and denoising with DADA2, taxonomic classification using SILVA, de novo phylogenetic tree construction, alpha and beta diversity analyses, longitudinal linear mixed-effects models, differential abundance testing with ANCOM-BC, MaAsLin2, and DESeq2, core microbiota analysis across prevalence thresholds, and functional profiling using PICRUSt2.

## Notebook pipeline
The analysis is organized as a sequential notebook pipeline. Notebooks depend on outputs generated by earlier steps and must be run in order. Running later notebooks without completing earlier ones will fail due to missing intermediate files. All required output directories and files are created automatically during execution.

The notebooks are structured as follows:
- 01 data import and overview
- 02 quality control and denoising
- 03 taxonomy
- 04 phylogeny
- 05 diversity analysis
- 06 longitudinal analysis
- 07 differential abundance analysis
- 08 core microbiota analysis
- 09 classification (exploratory, not used in final results)
- 10 functional profiling part 1
- 11 functional profiling part 2

## Repository structure
The scripts folder contains the main analysis notebooks. The scripts/additional folder contains helper scripts, including Euler and HPC scripts referenced in the notebooks. The doc folder contains the final written report. For the rest, all directories are made by the notebooks during analysis.

## Key findings (summary)
Age was the strongest driver of gut microbiome change, with increasing diversity and enrichment of anaerobic taxa such as Blautia, Roseburia, and Thomasclavelia. Feeding type and geographic location were associated with differences in community structure and core microbiota composition, while treatment exposure showed more limited effects. Breast-fed and formula-fed infants shared a large early-life core microbiota, with a small number of diet-specific core genera.

## Requirements
The analysis requires QIIME 2, Python with standard scientific libraries, R for differential abundance tools, and PICRUSt2. Exact environment details can be inferred from the notebooks or the environment directory.
